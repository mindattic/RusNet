# RusNet dependencies.
#
# The CORE of RusNet - scanning, the JSON map, and the self-contained HTML report
# (`python -m rusnet scan|report|viewer`) - needs NOTHING beyond the Python 3.9+
# standard library. These packages only enable the two optional surfaces below, and
# are what run.ps1 installs (pyproject.toml's [desktop,interfaces] extras).

# Native desktop viewer window with native file dialogs (`python -m rusnet.desktop`).
# On Windows it uses the built-in Edge WebView2 runtime.
pywebview>=5.0

# Cleaner cross-platform interface enumeration. Without it, RusNet falls back to
# parsing `ipconfig` (Windows) / `ip` (Linux), so this is optional but recommended.
psutil>=5.9
